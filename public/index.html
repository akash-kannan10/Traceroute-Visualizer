Computer Networks Concepts Explained

Academic guide to IP packet forwarding, ICMP protocol, and router discovery

How Traceroute Works (Step-by-Step TTL Mechanism)

Step 1
TTL = 1

Packet sent with Time-To-Live = 1. Router 1 decrements TTL to 0, drops the packet, and responds with ICMP Time Exceeded (Type 11).

➔
Step 2
TTL = 2

Packet passes Router 1 (TTL=1), reaches Router 2 (TTL=0). Router 2 drops packet and returns ICMP Time Exceeded.

➔
Step 3
TTL = N

TTL increments until reaching destination. Destination returns ICMP Echo Reply (Type 0), completing the trace.

🌐 What is Traceroute?

Traceroute (tracert on Windows) is a network diagnostic utility used to discover and display the sequential path (sequence of routers or hops) that IP packets traverse across an internetwork from a source host to a destination host.

🔄 What is a Hop?

In computer networking, a hop represents one intermediate routing step or device (such as a router, gateway, or switch) that forwards a data packet along the path between the sending client and receiving server.

🏷️ What is an IP Address?

An Internet Protocol (IP) Address is a unique numerical identifier assigned to every device connected to a computer network (e.g., IPv4: 192.168.1.1 or IPv6: 2001:db8::1). It facilitates packet addressing and routing across subnets.

⚡ What is Latency (Round-Trip Time)?

Latency measures the time delay (in milliseconds, ms) required for an ICMP probe packet to travel from the client to a specific router and for the acknowledgment response to return back to the client.

⏱️ What is Packet Loss / Timeout?

A "Request timed out" (*) occurs when an intermediate router does not reply within the timeout threshold. This is commonly caused by strict router firewall rules blocking ICMP traffic, rate-limiting, or congested network links.

🔀 What is a Router?

A Router is a Layer 3 (Network Layer) networking hardware device that connects multiple computer networks and intelligently forwards IP packets between them by examining destination IP addresses against its routing table.
